Slide 1 / 16
Why two, not one blob

One answers “what is intelligence?” The other answers “how do you build like big tech?”

Mixing them would blur numbering, sources, and rules. Separate folders, each with its own AGENTS.md, let a future agent load exactly one — and only one — for a task.

Intelligence — biological or artificial — is compression.

Brains and networks build predictive world models and improve by minimising prediction error. Shannon entropy ≈ cross-entropy loss ≈ cortical free energy.

Slide 11 / 16
How they fit together

Atlas tells you what to build towards. Playbook tells you how to build it so it survives.

Use the atlas to choose the architecture. Use the playbook to check the code before you ship it.

Slide 12 / 16
Isolation, in practice

No AGENTS.md at the repo root. No shared persona. No cross-links.

Each corpus's numbering is append-only and per-corpus. The GLM session transcript and raw log are NOT in this repo — research only, session internals stay private.

Slide 13 / 16
How to use this repo

Human: read a corpus README, then its playbook / reading order.

Agent, for one task: point it at exactly one corpus folder, read that folder's AGENTS.md first. Do not point an agent at the repo root and expect it to choose.

Slide 14 / 16
What is not here

Not exhaustive. Not current past October 2026. Not runnable adaptive code.

Not a textbook. Verify against cited sources before building on any single claim.
